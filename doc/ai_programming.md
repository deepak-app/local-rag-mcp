# Artificial Intelligence and Programming

Artificial Intelligence (AI) is transforming software development. 
Modern developers use large language models (LLMs) to write, debug, and optimize code faster than ever before.
Machine learning models are trained on vast datasets of public code, learning patterns, syntax structures, and programming paradigms.
Through techniques like semantic search and vector databases, developers can index entire repositories to find relevant code patterns or documentations.

## Vector Databases and Semantic Search
Vector databases represent text as high-dimensional embeddings where similar meanings are located close to each other.
Instead of matching exact keywords, a semantic search engine queries these vectors using cosine similarity or Euclidean distance.
This enables retrieval of contextually relevant information, even when the query uses completely different words than the document.
For example, searching for "instructions to cook spaghetti" can match a document describing "making a perfect Italian pasta."
Similarly, querying about "celestial bodies orbiting the sun" will retrieve text discussing "the planets of the solar system."
Using tools like FAISS (Facebook AI Similarity Search) and txtai, setting up a semantic search pipeline is fast, lightweight, and highly accurate.
